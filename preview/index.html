승인 전에 확인할 것

  1. Jimo 자산은 복사하지 않습니다. 우주 장갑 이미지, 로고, 문구는 쓰지 않고 레이아웃과 모션만 재현합니다. 장갑은 3D AI 커서 오브젝트로 바꿔 image-2.5-sunburst로 생성합니다 (위 프로토타입의 SVG 커서는 자리표시용).
  2. 생성할 이미지 (총 3장): 히어로 3D 커서(투명 PNG), 최종 CTA용 같은 커서 다른 포즈, OG 공유 이미지. 행성·별·그리드는 전부 캔버스 코드라 이미지가 필요 없습니다.
  3. 후기 문구가 필요합니다. 13번 인용 섹션과 12번 사례 카드에 실제 수료생/고객 후기와 수치를 넣어야 합니다. 받기 전까지는 하비탄 자체 문장("운영의 주도권은 고객의 팀에.")으로 채우고, 지어낸 후기는 넣지 않습니다.
  4. 기술 구성: 정적 단일 페이지(HTML + CSS + 바닐라 JS, 외부 라이브러리 없이 자체 스크롤 엔진). 기존 /shop, /contact 링크는 그대로 연결합니다.
  5. 반응형 · 접근성: 모바일에서는 핀 길이를 줄이고, prefers-reduced-motion이면 정적 레이아웃으로 바꿉니다.
